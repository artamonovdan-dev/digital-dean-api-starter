## Висновки та межі

Висновки стосуються лише цього середовища й розмірів. Швидкодія, правильність обчислення та криптографічні властивості — різні речі: частка ≈0,5 у 100 дослідах не доводить стійкості, а MD5 і SHA-1 мають відомі колізійні атаки, тому придатні лише для навчального порівняння. Хеш корисний для перевірки цілісності лише проти довіреного контрольного значення. Швидкі хеш-функції самі по собі непридатні для зберігання паролів — для цього потрібні повільні функції з сіллю (наприклад, Argon2, scrypt).

## Алфавітний глосарій

- **BLAKE2** — сімейство хеш-функцій; тут з явним 256-бітовим результатом.
- **IQR** (Interquartile Range) — міжквартильний розмах.
- **MD5** (Message Digest 5) — застарілий профіль, тільки навчальне порівняння.
- **SHA** (Secure Hash Algorithm) — сімейства SHA-1, SHA-2, SHA-3.
- **Відстань Геммінга** — кількість відмінних бітів двох рядків однакової довжини.
- **Лавинний ефект** — значна зміна хешу внаслідок зміни одного біта вхідних даних.
